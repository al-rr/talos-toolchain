# Claude Code Instructions

Read and follow `AGENTS.md` first.

For any cross-repository Talos work, also read:

1. `docs/planning/talos-projects-roadmap.md` — canonical decisions, iteration
   order, ownership, and status;
2. the matching record under `docs/planning/execution/` — active scope,
   implementer, reviewer, branch, acceptance criteria, and local review result.

Files under `docs/planning/reviews/` are historical independent reviews. They
support traceability but do not override the consolidated roadmap.

The collaboration workflow is local-first. Do not require a GitHub issue or
pull request to implement or review work. Do not push, open a pull request,
merge, rotate credentials, rewrite history, or run destructive infrastructure
commands without explicit owner authorization.
